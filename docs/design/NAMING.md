# Naming Exploration — One Photo, Many Possible Worlds

**Decision status:** Open. Use `photo-edit-agent` as the neutral working repository name until a final choice is made.

The product's distinctive interaction is not simply “an AI edits a photo.” It is the ability to explore alternative versions of the same photo, move between them, and preserve the paths that led there. That makes parallel worlds, alternate timelines, and branching possibilities useful creative themes.

## Multiverse-inspired shortlist

| Display name | Repository idea | Meaning and tone | Trade-off |
|---|---|---|---|
| **Frameverse** | `frameverse` | A frame with a universe of possible edits. Clear connection to images and the multiverse theme. | Needs a subtitle to distinguish editing from a broader visual platform. |
| **Elseframe** | `elseframe` | Another version of the frame: what the photo could become elsewhere. Compact and distinctive in tone. | An invented word whose meaning becomes clearer with the product description. |
| **Parallel Frames** | `parallel-frames` | The same moment explored through parallel versions. Calm, photographic, and less explicitly technical. | Longer to type; could also sound like a photography collection. |
| **Prismverse** | `prismverse` | A color-oriented universe of possibilities. Fits the initial grading experiment. | More stylized, with a weaker immediate connection to version history. |
| **Manyframes** | `manyframes` | A subtle nod to many possible worlds, expressed in photographic language. Friendly and approachable. | Could suggest batch editing rather than branches of one photo. |
| **Alterframe** | `alterframe` | Alternate frames and altered photographs in one name. Direct enough for an editing tool. | Emphasizes modification more than recovering and comparing versions. |

These are creative proposals. No availability, domain, trademark, organization-name, or repository search was performed for this shortlist. Do not describe a name as unique, available, reserved, or cleared.

## Recommendation

**Frameverse** is the strongest match for the requested multiverse direction while keeping a visible connection to photography.

Possible presentation:

```text
Frameverse
One photo. Every possibility.

AI-assisted photo editing with branching history, powered by GIMP.
```

For a more understated name, choose **Parallel Frames**. For a shorter invented brand, choose **Elseframe**:

```text
Elseframe
See what else it could be.
```

These are naming judgments, not claims about implementation status or product availability.

## The straightforward alternative

`photo-edit-agent` remains a good descriptive repository name for a personal experiment:

```text
Photo Edit Agent
AI-assisted photo editing with a history you can branch, compare, and restore.
```

The repository name and display name can remain separate while the concept settles. Avoid changing paths, identifiers, and documentation repeatedly during naming exploration. Record one explicit naming decision, then make a consistent update.

## Suggested repository description

This description states the intended direction, not that all capabilities are implemented:

```text
A local-first workbench for AI-assisted photo editing with branching history, powered by GIMP.
```

Keep the implementation-status notice prominent in the README regardless of which name is chosen.
