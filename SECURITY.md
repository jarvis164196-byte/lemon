# Security

Lemon is an experimental local application, not a hosted multi-user service. Do not bind it to a public interface, reverse-proxy it onto the internet, or share its private launch URL. Project directories contain private photos and logs. The native GIMP process runs as your OS user; an operation allowlist is not a process sandbox.

For a security issue, use GitHub's private vulnerability reporting when enabled. Do not include private images, launch tokens, credentials, or absolute personal paths in public issues.
